# Only assets whose licence allows redistribution

The repository is public, so every art or sound file committed to it is redistributed to anyone who clones it. Only assets whose licence explicitly allows redistributing the original files go in the repo, CC0 preferred, each recorded in `ASSETS.md` with its source and licence. The avatar sprites are JIK-A-4's MetroCity pack (CC0).

## Considered options

- shubibubi's Cozy People (paid; "can't be resold or redistributed even if modified"): it fitted the cozy style, but would have forced the PNGs out of git into private storage fetched at build time. It was removed from the repo and from its history.
