# Tileset research

Status: needs-triage
Type: research

## What

Find a tileset for floor, walls and furniture that matches the MetroCity character sprites (32×32 frames, a body about 14×28 px, 16 px tiles) in style and scale. The repo is public, so the licence must allow redistributing the files ([ADR-0011](../../../docs/adr/0011-only-redistributable-assets.md)); CC0 is preferred. Not part of the MVP; the MVP map uses plain shapes.

## Acceptance criteria

- [ ] Candidates listed with licence terms quoted from the primary source, starting with JIK-A-4's own packs.
- [ ] One recommended, with what attribution it needs.
