# 02 — Light sources declared on Tiled tiles

**What to build:** Replace `lights.png` with light sources declared on the objects tileset (ADR-0029). The `lamp` tile declares `glow = warm` and the `stage` tile `glow = stage`, each with the offset to its bulb. The map generator exports one light source per placed object, and the engine draws a first-party glow sprite (add blend) for each one in a light layer above the scene, outside the Ambient light. The Lamp glow level is the share of sources switched on: each source has a fixed threshold derived from its position and fades in or out when the level crosses it. Lit sources breathe faintly.
