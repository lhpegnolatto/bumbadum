# 05 — Persistent room Settings

**What to build:** Give the Player an always-visible lower-left Settings control for language and theme while keeping volume solely with the Radio.

**Blocked by:** 02 — Screen and Radio overlay the world.

**Status:** resolved

- [x] Language and theme remain persisted and reflected immediately; popover state is ephemeral.
- [x] Volume appears only in the Radio bar and retains its existing persistence and focus-restoration behavior.
- [x] New labels and tooltips remain equivalent in English and Brazilian Portuguese.
