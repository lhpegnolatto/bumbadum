# 06 — Wardrobe integrated with room overlays

**What to build:** Keep Wardrobe immediately accessible while giving the editor enough space over the world and ensuring it never hides the Screen or conflicts with another room overlay.

**Blocked by:** 03 — Exclusive navigation between Chat, Queue and Players; 05 — Persistent room Settings.

**Status:** resolved

- [x] Wardrobe and Settings controls form an always-visible lower-left group.
- [x] Wardrobe opens in a wider overlay over the world without intersecting the Screen.
- [x] Opening Wardrobe closes an active room panel or Settings popover, and opening another interface closes Wardrobe.
- [x] The `C` shortcut, Apply, close, Escape and draft-discard semantics remain unchanged.
- [x] Closing Wardrobe returns movement controls to the world.
- [x] Existing private preview, publication and persistence behavior remains covered end to end.
